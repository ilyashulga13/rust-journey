# Hello World (Chapter 1)

This is my first Rust project, created while reading [The Rust Programming Language](https://doc.rust-lang.org/book/ch01-00-getting-started.html) book.

## What it does
It simply prints `Hello, world!` to the console. This is the traditional starting point for learning any new programming language.

## How to run

Make sure you have Rust and Cargo installed. 

1. Navigate to this folder:
   ```bash
   cd hello_world
   ```
2. Run the project:
   ```bash
   cargo run
   ```

## Code
Here is the source code in `src/main.rs`:
```rust
fn main() {
    println!("Hello, world!");
}
```
